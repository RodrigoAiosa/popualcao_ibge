# 📊 População dos Municípios Brasileiros

Aplicação Streamlit para visualização das estimativas populacionais dos municípios brasileiros, utilizando dados oficiais do IBGE (SIDRA - Tabela 6579).

## 🚀 Funcionalidades

- Carregamento automático de dados do SIDRA/IBGE
- Filtros por UF e faixa populacional
- Visualizações interativas com Plotly
- Tabelas detalhadas com ordenação
- Download dos dados em CSV
- Cache local para evitar recarregamentos desnecessários
